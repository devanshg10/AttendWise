# AttendWise — Smart Attendance & Bunk Calculator

A clean, modern web application for college students to track attendance and calculate safe bunks.

## Features
- **Attendance Tracker**: Log attended and missed classes with one click.
- **Bunk Calculator**: Tells you exactly how many classes you can safely bunk without falling below your target percentage (e.g. 75%).
- **Recovery Planner**: Calculates how many consecutive classes you must attend to get back on track if attendance is low.
- **Charts & Statistics**: Visual graphs and subject-wise breakdown.
- **Light & Dark Mode**: Easy toggle between dark and light themes.
- **Saved Automatically**: Saves all data in your browser's local storage (no account or login needed).
- **Export & Import**: Download your attendance data as a JSON file and restore it anytime.

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
- Chart.js (CDN)
- Lucide Icons (CDN)
